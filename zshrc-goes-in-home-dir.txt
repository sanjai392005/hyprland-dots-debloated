# ========================== NVIM TIPS ================================
# good resource = https://vimschool.netlify.app/basics/navigatingext/
# mouse select and then 'y' -> copying 
# esc then 'i' -> insert mode 
# esc then 'v' for visual mode 
# mouse select and then 'del' -> for deleting selected text 
# mouse select and then 'd' -> for cut 
# mouse select and then del -> for delete
# esc then 'u' -> undo 
# esc + space + fe --> file explorer
# go to a directory + 'a' + type the relative path of new file --> creating new file
# visual selection + '>' --> alternative to moving selection by above
# esc + : + 'e' + path to file --> open a diff file in the given path in nvim another tab
# esc + '$' --> EOL
# esc + '^' --> BOL 
# esc + 'g'g' --> top of page
# esc + 'G' --> bottom of page
# esc + space + 'f''T' --> terminal
